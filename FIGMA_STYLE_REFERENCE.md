# Figma style reference used by this project

Source:
https://www.figma.com/design/92mI0ghNGF0jviGxqhM2Ym/Even-Realities---Software-Design-Guidelines--Public---Copy-?node-id=2922-80782&p=f&t=TTgNoS6eTnHy9qZh-0

The source implementation was derived from the Figma Conversate and Settings examples.

## Conversate pattern
- Reference frame width: 393 px/dp
- Main background: #EEEEEE
- Nav header after system status bar
- Conversation progress card at 12 px horizontal margin
- Two equal-width tabs with 2 px selected underline
- Main white content card, 6 px radius
- 16 px internal padding
- CTA row using 48 px tall, 6 px radius buttons
- Primary text: #232323
- Secondary text: #7B7B7B
- Title: 17
- Body: 15
- Subtitle: 13
- Detail: 11

## Settings pattern
- Grouped white list cards on #EEEEEE
- 16 px row padding
- 24 px icon region
- 16 px icon-to-text gap
- Compact right-hand detail/chevron area
- Section headers at 13 px
- Slider inside white 6 px card
- Minimal borders and no elevation-heavy Material styling

The proprietary FK Grotesk Neue reference font is not included in this repository. Preserve hierarchy and geometry using system sans or a legally redistributable substitute.
